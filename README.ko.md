# 윗마이펫 · With My Pet 🐾

반려동물과 함께 갈 수 있는 곳(숙소·식당·카페·공원·병원)을 찾고, 여행 코스를 만들고, 후기를 나누고, 펫 여행용품까지 담을 수 있는 **반려동물 동반 여행 앱**입니다. 빌드 과정 없이 브라우저에서 바로 동작하는 **정적 SPA**(데모 모드)입니다.

## 소개

윗마이펫은 반려인이 반려동물과 함께 떠나는 여행을 계획하도록 돕습니다. 40곳 이상의 (가상) 반려동물 동반 장소를 지역·카테고리·반려동물 크기·편의시설로 탐색하고, 반려동물 정책과 후기를 확인하고, 마음에 드는 곳을 나만의 여행 코스에 담고, 커뮤니티 후기를 남기고, 반려동물 프로필을 만들고, 여행용품을 모의 장바구니에 담을 수 있습니다. 프레임워크·의존성 없는 무빌드 단일 페이지 앱입니다.

## 주요 기능

- **장소 탐색** — 지역·카테고리(숙소/식당/카페/공원/병원)·허용 크기(소/중/대형견)·편의시설(울타리·주차·수영장·놀이터·펫 샤워장 …) 필터, 검색, 정렬(평점/후기수/이름/가격).
- **장소 상세** — 반려동물 정책, 이용시간, 허용 크기, 편의시설, 개략 위치, 후기.
- **지도 뷰** — 인라인 SVG로 만든 지역 개략 지도. 지역을 누르면 해당 지역 장소 목록 표시. 외부 지도 키 불필요.
- **커뮤니티** — 별점과 플레이스홀더 사진이 있는 후기 열람/작성.
- **반려동물 프로필** — 이름·견종·크기·한 줄 소개, 자동 생성 아바타.
- **여행 코스 만들기** — 장소를 담아 코스 구성, 순서 변경·삭제.
- **용품 카탈로그 + 장바구니** — 20개 이상 여행용품, 카테고리 필터·검색, 수량 조절 모의 장바구니와 모의 결제.
- **찜** — 좋아하는 장소 저장, 프로필에 모아보기.
- **부가 기능** — 여행 전 **동반 체크리스트**(진행률 표시), **응급 동물병원 빠른찾기**(24시/야간 병원, 전화 걸기).
- 라이트/다크 테마, 모바일 우선 반응형 UI, localStorage 저장 + 한 번에 초기화.

## 🟡 데모 모드 범위 (꼭 확인하세요)

이 앱은 데모용 프론트엔드입니다. **굵게** 표기한 부분:

- **모든 장소·용품·가격은 가상의 시드 데이터**이며 `data/*.json`에서 불러옵니다. 실제 업체가 아닙니다.
- **지도는 개략적인 SVG 레이아웃이며 실제/실시간 지도가 아닙니다.** 지리적 정확성이 없습니다.
- **모든 이미지는 인라인 SVG 플레이스홀더**이며 실제 사진이 아닙니다.
- **데이터는 브라우저 localStorage에만 저장되며 실제 데이터베이스가 아닙니다.** 사이트 데이터 삭제나 앱 내 초기화 시 사라지고, 어디에도 동기화되지 않습니다.
- **실제 계정·결제·개인정보(PII) 수집·실제 지도 서비스가 없습니다.** "모의 결제"는 실제 청구가 없습니다.
- **실제 서비스라면** 백엔드+실 DB, 실제 지도/위치, 인증, 실제 결제, 콘텐츠 검수가 추가됩니다.

## 로컬 실행

빌드·의존성이 없습니다. ES 모듈 특성상 HTTP로 서빙해야 합니다:

```bash
# Python
python -m http.server 8975
# http://localhost:8975 접속

# 또는 Node
npx serve .
```

## 기술 스택

- 순수 **HTML + CSS + ES 모듈 JavaScript**, 프레임워크·번들러 없음.
- 루트의 `index.html`, 상대 경로만 사용, GitHub Pages 배포 그대로 가능.
- 시드 데이터는 `data/*.json`, 상태는 `localStorage` 저장(try/catch + 메모리 폴백).
- 아트·아이콘·아바타·지도 전부 인라인 SVG.

## CI

`node check.mjs` 가 다음을 검증합니다: `data/*.json` 파싱, 시드 개수(장소 ≥40, 용품 ≥20), 모든 JS의 `node --check`, `index.html`의 필수 컨테이너 존재. GitHub Actions(`.github/workflows/ci.yml`)에서 실행됩니다.
